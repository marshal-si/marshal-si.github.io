MARSHAL LOGO ASSETS
===================

Approved visual direction: geometric orange M, charcoal lowercase wordmark, and
“ENGINEERED. EVIDENCED. GOVERNED.” tagline.

Files
-----
marshal-mark-profile.png / @2x.png
  M-only profile/avatar asset, transparent background, square-ish crop.

marshal-mark-and-wordmark.png / @2x.png
  M + “marshal” wordmark, without tagline; useful for compact profile use,
  headers and smaller placements.

marshal-full-logo.png / @2x.png
  Full lockup including tagline; transparent background, suitable for documents
  and websites.

*-white-background.jpg
  White-background alternatives for applications that handle transparency poorly.

marshal-email-template.html
  Simple editable HTML email template. Keep marshal-full-logo.png in the same
  folder when previewing it. Replace the bracketed contact/domain placeholders.

Colour guidance
---------------
Orange: approximately #C94F19
Charcoal: approximately #242321
Warm ivory (presentation background): approximately #F7F5EF

Notes
-----
These are raster PNG/JPEG assets prepared from the approved logo concept. They
are high-resolution and suitable for typical web, profile, document and email
use. The source artwork is not a true vector master; a hand-built SVG/vector
master would be a separate production step.
